Embed

jtoh.pro has a built-in embed feature that allows you to embed stat cards into your own website! Below is instructions on how to implement it into your own website.

How to Embed

The first step is to include the script tag and stylesheet in the head of your html file. 
                    <script src="https://jtoh.pro/embeddable/script.js"></script>
<link rel="stylesheet" href="https://jtoh.pro/embeddable/style.css" />
Once you have that, you'll need to create a div element for the embed. Make sure to give it an id. jtohProEmbed will be used in this example. 
                    <div id="jtohProEmbed"></div>
The final element we need to create is a script tag. This will be used to create the embed. You can put this script tag anywhere you would like. (Or skip this step if you already have a script tag in your html file.) An example of all the html combined can be found at the bottom of this guide! 
                <script></script>
Now that you the html elements in place, you can use the globalThis.jtohProEmbed object in a script tag to create the embed. You'll likely want to do this after the page loads. This is to ensure the globalThis object is available. On top of that, make sure your event listener is an async function. This is because the new method returns a promise. Note that the new method requires the container element to be passed as the first argument. This is the id of the div element you created earlier.

The embed object returns two methods:
- set - Sets the embed to display a stat card. This method takes three arguments.
     - usernameOrId (string|number) - The user to display. This can be a username or a user id. (User id must be a number.)
     - game (string) - The acronym of the game to get the user's stats for. Available games are:
     - [OPTIONAL] urlSuffix? (string|undefined) - Option query string to append to the end of the request URL. Note that you do not need to include the & symbol unless you have multiple query parameters. Example: foo=true&bar=false.

- delete - Deletes the embed. This method takes no arguments. NOTE: This method will not delete the embed's container element. 
                    // Listen for the page to load.
window.addEventListener('load', async () => {
    // Create the embed.
    const embed = await globalThis.jtohProEmbed.new('jtohProEmbed');
    
    // Say we want to embed a CSCD card, we can do the following:
    await embed.set('LoveliestJacob', 'cscd', 'mode=legit');

    // Later down the road, if we want to delete the embed, we can do the following:
    // embed.delete();
})
Our final example will look like this: 
            <!doctype html>
<html>
    <head>
        <script src="https://jtoh.pro/embeddable/script.js"></script>
        <link rel="stylesheet" href="https://jtoh.pro/embeddable/style.css" />
        <script>
            window.addEventListener('load', async () => {
                const embed = await globalThis.jtohProEmbed.new('jtohProEmbed');
                await embed.set('Roblox', 'cscd', 'mode=legit');
            });
        </script>
    </head>

    <body>
        <div id="jtohProEmbed"></div>
    </body>
</html>
Note that if you would like to edit the stylesheet, you can do so by modifying the style.css css file. You can also use your own stylesheet of course. All elements are prefixed with jtoh-pro- to avoid conflicts with your own styles. You are not required to keep the link to jtoh.pro visible, however we would appreciate it if you did.
