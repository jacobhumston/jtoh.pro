Frequently Asked Questions (FAQ)

How do I customize my card?

Click the settings icon at the top of every page. You are required to be logged in first!

How are stats gathered?

In partnership with TowerStats.com we were granted access to an API that allows us to access the same stats that you can see on their website. TowerStats.com gets data from multiple sources, primarily Roblox badges.
Note that jtoh.pro relies on the API provided to be up to date. In the case that data is not up to date, please let us know!

Something is outdated!

If you notice something is outdated, please join our Discord Server and let us know!

How are Skill Points (SP) calculated?

Skill Points are calculated using a formula created by SirSamiboi. You can find the source code (as well as an explanation of the formula) on their GitHub repository. Note that our implementation may differ slightly, however the overall concept and execution remains generally the same.

The image is outdated when sent on Discord, what's wrong?

Discord saves (or technically known as "caches") the image when it is first sent. This means that if the same exact URL is sent again, Discord will display the cached image for a while instead of fetching a new one. To prevent this from happening:
- Copy or download the image from the 'Try it out!' section.
- Add a random query string to the end of the URL, such as ?abc1234 .
- Use the "Copy URL" button provided on the 'Try it out!' section, as it automatically adds a nocache query string for you.
- Use our Discord Bot , which will always provide the latest image.
If none of the above fixes your problem, wait at least 5 minutes before sending the image again.

Will other fan games be supported?

Yes! I will add fan game support as they are added to towerstats.com

Are banned accounts supported?

Banned accounts are supported but may have inaccurate results. For example, if the account played the original JToH place but never joined the current EToH place; then they may not have any stats displayed.
