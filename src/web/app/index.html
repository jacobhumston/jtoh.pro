jtoh.pro

Easily share your Juke's Towers of Hell stats/progress on Discord or other social medias with a single link. Statistics are provided by towerstats.com.

Try it out!

Input a Roblox username bellow to try it out! You can also input a user ID by starting the input with an exclamation mark.

Available Links

Note that {USER} can either be a username or a Roblox user ID. The user ID must start with an exclamation mark, such as !12345.
jtoh.pro/{USER} - Get an image of a user's tower stats.
jtoh.pro/embed/{USER} - Get an image of a user's tower stats as a Discord embed. The link will open the user's towerstats.com profile.
jtoh.pro/screenshot/{TYPE}/{USER} - Get a screenshot of a user's tower stats from towerstats.com. Supported types include...
  • difficulty - A screenshot of the user's difficulty completions.

Short Links

jtoh.pro/e/{USER} - Short link for jtoh.pro/embed/{USER}.
jtoh.pro/s/{TYPE}/{USER} - Short link for jtoh.pro/screenshot/{TYPE}/{USER}.

Tips & Recommendations

  • If your image is out of date when sent on Discord; add #random_letters to the end of the URL. This will bypass Discord's image cache. Example: jtoh.pro/roblox#abc123
  • Depending on how busy the backend server is, and if you've ever loaded your stats before, then the image may take longer to load. It's also important to keep in mind that banned or deactivated accounts are not supported.
