jtoh.pro

Easily share your Juke's Towers of Hell stats/progress on Discord or other social medias with a single link. Statistics are provided by towerstats.com

Try it out!

Input a Roblox username below to try it out! You can also input a user ID by starting the input with an exclamation mark.

Available Links

Note that {USER} can either be a username or a Roblox user ID. The user ID must start with an exclamation mark, such as !12345 .
/{USER} - Get an image of a user's tower stats.
/embed/{USER} - Get an image of a user's tower stats as a Discord embed. The link will open the user's towerstats.com profile.

Short Links

/e/{USER} - Short link an embed.
