Input a Roblox username below to try it out! You can also input a user ID by starting the input with an exclamation mark.

Available Links

Note that {USER} can either be a username or a Roblox user ID. The user ID must start with an exclamation mark, such as !12345

All CSCD links support the mode query. Such as ?mode=aj at the end of the URL. aj is for All Jumps and legit is for Legit wins. If a mode isn't specified, then it will displays Legit or All Jumps depending on whichever mode has any completions. Legit mode takes priority over All Jumps.

/cscd/{USER} description
info Get an image of a user's tower stats.
/cscd/embed/{USER} description
info Get an image of a user's tower stats as a Discord embed.
The link will redirect to the user's towerstats.com profile when opened.

Short Links

Short links are links that redirect to "bigger" links. They are useful for sharing links in a more compact way.
/cscd/e/{USER} description
info Short link for /cscd/embed/{USER}
/c/{PATH} description
info Short link for /cscd/{PATH}
