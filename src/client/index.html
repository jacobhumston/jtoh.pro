Welcome

 jtoh.pro is a web utility for the Roblox game known as Juke's Towers of Hell. You can view any Roblox's accounts tower stats and more.

 To get started, add an account using the button provided to you on the top right of this page. You'll be requested to enter the username of the account. No password required.

 Note that the idea behind this website is based off of jtoh.info.
I created this website because I wanted more features.
